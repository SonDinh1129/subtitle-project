## Endpoint mới: `GET /api/jobs/<job_id>/translation-quality`

```
GET /api/jobs/abc123/translation-quality?model=gpt-4o-mini
Authorization: Bearer <JWT>
```

**Query params:**
- `model`: `gpt-4o-mini` (default) hoặc `gpt-4o` — allowlist cứng, model khác trả 400

**Response:**
```json
{
  "model": "gpt-4o-mini",
  "total_pairs": 87,
  "evaluated_pairs": 87,
  "scores": { "avg": 7.4, "min": 4, "max": 10 },
  "pairs": [
    {
      "en": "Welcome to the show",
      "vi": "Chào mừng đến với chương trình",
      "score": 9,
      "issues": [],
      "comment": "Accurate and natural translation"
    }
  ]
}
```

**Điều kiện:**
- Job phải `status == "done"`
- Chỉ owner mới gọi được (403 nếu không phải)
- Rate limit: 10/minute
- Yêu cầu `OPENAI_API_KEY` trong `.env` (503 nếu thiếu)

---

## Kiến trúc `translation_quality.py`

- **Zero external packages** — chỉ dùng `urllib.request` + `json` stdlib
- **Prompt format:** yêu cầu `{"evaluations": [...]}` (json_object mode compatible)
- **`_safe_score()`** — clamp 1–10, float-safe, default 5 khi model trả string/null
- **`_safe_issues()`** — coerce về `list[str]` bất kể model trả gì
- **`_escape_for_prompt()`** — escape double-quote trong subtitle trước khi nhúng vào prompt
- **Token estimation** — tính cả overhead prompt (~600 chars) + per-pair format (~20 chars), safety cap 100k tokens
- **Truncation** — nếu vượt token limit: `pairs_all[:max_pairs]` (tuyến tính, đơn giản)
- **API key** — đọc trực tiếp trong `_call_openai()` từ `os.environ`, không truyền qua tham số (tránh lộ trong traceback/Sentry)

**Error handling trong controller:**
```
EnvironmentError → 503 (API key chưa set)
urllib.error.HTTPError 429 → 429 (OpenAI rate limit, retry-able)
urllib.error.HTTPError other → 502 (OpenAI API error)
urllib.error.URLError → 502 (network error)
ValueError → 422 (model không hợp lệ, không có pairs, response lỗi)
Exception → 502 + server log
```

### Đã biết còn hở (minor, không block)
- **Sentence count mismatch** — khi EN và VI words có số câu lệch > 5, controller log warning nhưng vẫn xử lý (zip truncate). Chưa có cơ chế align lại. Xem log: `Sentence count mismatch for job X: EN=Y VI=Z`.
- **Blocking I/O** — `urllib.request` chạy sync trong Flask request thread, timeout 30s. Đủ cho gpt-4o-mini nhưng nếu traffic cao cần chuyển sang async task (Celery hoặc threading tương tự async export).
- **OpenAI model price control** — chỉ cho phép `gpt-4o-mini` và `gpt-4o`. Nếu muốn thêm model khác, sửa `ALLOWED_MODELS` trong `models/translation_quality.py`.
